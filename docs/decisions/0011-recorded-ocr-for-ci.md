# ADR-0011 — Recorded OCR, keyed by page image, for CI

**Status:** accepted · **Date:** 2026-08-11

## Context

PaddleOCR needs several hundred megabytes of model weights and a GPU to be tolerable, and
Qwen2.5-VL needs a GPU outright. Neither can run in CI. Without a substitute, everything
downstream of recognition — preprocessing decisions, confidence scoring, VLM escalation, block
assembly, structure detection, the review editor's payload, the publish path for a scanned
document — would be untested, and the twenty-document acceptance criterion unrunnable.

## Decision

`OcrPort` and `VlmPort` each get a **recorded** adapter that replays results keyed by the
SHA-256 of the *preprocessed page image*.

The key is the design. A change anywhere in rasterization or preprocessing changes the image,
changes the key, misses the recording, and fails the test loudly. A recording keyed by filename
or page number would silently replay stale output for an image that no longer exists — worse
than having no test, because it would look like one.

Recordings are generated by `kb_idp.testing.make_scans`, which renders known Vietnamese ground
truth, damages it the way the archive's documents are damaged, and derives the "recognized"
lines from that ground truth with the error modes real scans produce: tone marks lost, speckle
read as punctuation. Escalating fixtures get output bad enough to fail the confidence score,
and a VLM recording that returns the ground truth — so the tests can assert that escalation
*improves* the result rather than merely changing it.

## Consequences

CI runs the whole scanned route on twenty documents in about twenty seconds. What it measures
is the pipeline: routing, scoring, escalation, assembly, review, publish. It measures nothing
about PaddleOCR's accuracy, and both adapters say so in their `info` (`real_ocr: False`), so a
report built from them cannot be mistaken for a production measurement.

Changing preprocessing means regenerating the fixtures — deliberately. The diff shows exactly
which pages changed, which is the review the change deserves.
